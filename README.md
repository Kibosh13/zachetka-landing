# Учебный Советник — лендинг консультационных услуг по учебным работам

Одностраничный сайт на чистом HTML/CSS/JS. Без сборки и зависимостей — достаточно открыть `index.html`
или залить папку на любой хостинг (GitHub Pages, Netlify, Vercel, обычный shared-хостинг).

## Структура

```
index.html              вся разметка страницы
assets/css/styles.css   дизайн-система и стили
assets/css/fonts.css    подключение локального шрифта
assets/js/main.js       прайс, калькулятор, форма, анимации
assets/fonts/*.woff2    Manrope (variable 200–800), кириллица и латиница, 40 КБ
assets/img/favicon.svg  иконка сайта
assets/img/og.svg       превью для мессенджеров и соцсетей
```

Шрифт лежит локально, а не подгружается с Google Fonts — сайт одинаково быстро открывается
у пользователей в России и не зависит от доступности внешнего CDN.

## Что есть на странице

- Первый экран с ключевым обещанием, метриками и бегущей строкой услуг
- Шесть карточек направлений с ценой «от»
- Четыре шага процесса работы
- Прайс-лист с переключением категорий (на мобильных превращается в карточки)
- Калькулятор стоимости: тип работы × дисциплина × срочность + допуслуги
- Блок гарантий и условий оплаты
- FAQ-аккордеон
- Форма заявки с валидацией

## Прайс и калькулятор

Все цены лежат в одном месте — массиве `PRICE_DATA` в начале `assets/js/main.js`.
Таблица прайса и список в калькуляторе строятся из него, поэтому цену достаточно поменять один раз.

Поле `calc` у услуги отвечает за калькулятор:

```js
{ name: 'Курсовая работа (теоретическая)', volume: '25–35 стр.', term: '7–14 дней',
  price: '2 000 – 6 000 ₽', calc: { min: 2000, max: 6000, term: '7–14 дней' } }
```

`calc: null` — услуга видна в прайсе, но не участвует в калькуляторе (например, цены за страницу
или надбавки в процентах).

Коэффициенты калькулятора заданы в разметке, в `data-value` у кнопок:
техническая дисциплина `1.3`, ускоренный срок `1.5`, срочный `2`. Допуслуги — `data-add` в рублях.

## Форма заявки

Бэкенда нет: по кнопке «Отправить заявку» собирается письмо и открывается почтовый клиент.
Чтобы заявки приходили в CRM или Telegram, замените в `initForm()` блок с `window.location.href = mailto:`
на обычный запрос:

```js
await fetch('/api/lead', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ name: name.value, contact: contact.value, topic: topic.value })
});
```
